# Codex build brief for the Julington Dental homepage mockup

Build a responsive homepage from `Julington_Dental_Homepage_Mockup.png`. Treat the PNG as the visual source of truth for the desktop design. Use the supplied assets in `assets/` so the logo and service imagery match the mockup.

## Design and content

- Keep Julington Dental’s existing black and gold identity, logo, and contact number. Use a soft cream background, restrained gold accents, and generous whitespace in place of large black page backgrounds.
- Match the mockup’s section order: header, brand-led hero with the real practice photo, three service groups, practice introduction with a cleaning image, four featured services, patient video stories, written patient reviews, location map, appointment call to action, footer.
- Recreate the three gold icons and labels under the hero: **Preventive Dentistry** (cleanings, exams, fluoride), **Restorative Care** (implants, crowns, dentures), and **Other Ways to Thrive** (cosmetic dentistry, sleep apnea, TMJ). Link terms only to matching sections built on the concept page; show other terms as plain text. Avoid keyword stuffing.
- Keep the hero short for mobile: “Smile Brighter with Julington Dental,” “General dentistry in St. Johns, FL,” and “Preventive, restorative and cosmetic care.” Do not restore the long introductory paragraph.
- Preserve the current homepage’s core information. Feature Dental Implants, Same-Day Crowns, Clear Aligners, and Dentures. Cross-check final service copy and links against `https://julingtondental.com/` and its service pages.
- Replace the blog area with patient stories and reviews. Use the supplied screenshots of Tim, Jane, and Barbara and Jonathan as video thumbnails. Their names are already in the screenshots, so do not add duplicate captions. Verify each video URL before linking.
- Add three five-star review cards based on the supplied Google review screenshots. Display the reviewers as **Michelle R.**, **Jeff A.**, and **Mayelyn B.** Use only their actual supplied words. The mockup quotes are excerpts, not full reviews. Check current publication status and obtain practice approval before a public launch.
- Use the supplied location screenshot in the concept. For the built site, use an accessible map or an image linked to a verified Google Maps directions URL. Keep the address beside it: 106 Julington Plaza Drive, Suite 6, St. Johns, FL 32259.
- Use the supplied official logo and existing practice photo. The cleaning and service images are illustrative concept assets; ask Julington Dental to approve them before using them on an official site.
- Keep a small visible label on the preview: “Design mockup prepared by Klein Marketing. Not the official Julington Dental website.” Remove that label only if Julington Dental approves a production launch.

## Function and quality

- Make the layout responsive for desktop, tablet, and phone. On phones, stack the three service groups, service cards, reviews, and map, and make the appointment button easy to tap.
- Use semantic headings, descriptive image alt text, visible keyboard focus, sufficient color contrast, and a reduced-motion friendly design.
- Link appointment buttons to the concept's contact section, which includes the practice phone number. Do not add a patient intake form to the concept preview.
- Make navigation, service links, phone links, directions, and video links functional. Verify every destination before deployment.
- Keep assets local in the repository. Optimize images for web delivery without changing their appearance significantly.
- Add a short README with local run instructions, asset sources, and the deployment URL once published.

## Repository and preview

1. Put the source and supplied assets in a new repository or an approved project folder. Keep the existing Julington Dental website untouched.
2. Build and test the page locally at desktop and mobile widths. Compare it against the PNG and fix visible layout differences.
3. Publish a **real staging URL** from the chosen host. A made-up URL will not work for the proposal QR code. Keep the concept label visible on the staging site.
4. Test the staging URL in a signed-out browser and on a phone. Confirm images load and the appointment and phone links work.
5. Generate the proposal QR code from that exact live staging URL. Scan the printed proposal before delivering it.

## Image generation prompts used

- **Implants:** Close editorial image of gloved hands holding a realistic dental implant model and crown in a bright clinic, no faces or text.
- **Crowns:** Ceramic dental crown with shade guide and chairside milling equipment softly visible in a bright clinic, no faces or text.
- **Aligners:** Clear aligner tray held above a dental model in a bright clinic, no faces or text.
- **Dentures:** Tasteful editorial image of removable dentures in a clean dental tray beside a shade guide, warm cream tones, no faces or text.
- **Cleaning:** Realistic side view of a patient receiving a dental cleaning in a warm office with wood cabinetry and bright natural light, guided by supplied Julington Dental office imagery; provider face outside the frame, no visible logos or text.
